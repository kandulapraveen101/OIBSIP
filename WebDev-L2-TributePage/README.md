## 📌 Project Overview

An interactive, visually engaging **Tribute Page** dedicated to **Nikola Tesla (1856–1943)**, legendary inventor, electrical engineer, and visionary pioneer of polyphase Alternating Current (AC) power, high-voltage physics, and wireless communication.

Built with semantic **HTML5**, modern **CSS3** (glassmorphism, design tokens, dual font hierarchy, high-contrast dark obsidian theme), and vanilla **JavaScript ES6+** (interactive timeline filter, quote carousel, and an HTML5 Canvas Tesla Coil spark simulator).

---

## 🛠️ Feature Checklist & Compliance

- [x] **Page Title & Tagline:** `Nikola Tesla — Architect of the Electrical Age & Visionary Futurist`
- [x] **Prominent Image:** Royalty-free generated artwork with glowing electric aura, caption, and credit line.
- [x] **Original Biography:** 4 detailed narrative sections covering *Early Life & Polyphase Genius*, *War of Currents & Niagara Illumination*, *High Frequency, Radio Waves & Wardenclyffe*, and *Enduring Legacy*.
- [x] **Interactive Timeline:** Chronological milestones from 1856 to 1943 with category filter buttons (*All*, *AC Power Systems*, *Wireless & Radio*, *Major Patents*).
- [x] **Distinct Quote Block:** Interactive carousel showcasing famous Tesla quotes with gold serif quotes and author citations.
- [x] **Multiple Background Palettes:** Obsidian Slate (`#07080d`), Deep Indigo (`#0e1222`), Slate Navy (`#14192d`), Translucent Violet (`#16112c`), and Deep Mineral (`#040508`).
- [x] **Dual Font Hierarchy:** `Cinzel` (classic regal serif headings) + `Inter` (crisp sans-serif body text) + `Fira Code` (monospace patent badges).
- [x] **Interactive Physics Lab:** Real-time HTML5 Canvas Tesla Coil spark discharge simulator.
- [x] **Responsive Design:** Mobile menu drawer, fluid typography (`clamp()`), and responsive grid/flexbox layouts.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone git@github.com:kandulapraveen101/OIBSIP.git
   cd OIBSIP/WebDev-L2-TributePage
   ```

2. **Open in browser:**
   - Double-click `index.html` to open directly in any web browser.
   - Or start a local server:
     ```bash
     python -m http.server 8080
     ```
   - Navigate to `http://localhost:8080` in your web browser.
